# Shared checklist publication

Gmail access runs only through a separately configured local Codex task. Never commit private runtime files or credentials. Routine publications may change only the authorized company/role/status checklist and its generated `docs/public-data.json` copy. Run tests and `npm run build:pages` before committing. Push without force, verify deployment, and report failures. Preserve browser-only edits and private local records. The website itself never accesses Gmail.
